# 42 — 再平衡与退出（核心月度轮动 + 卫星事件退出）

> 本文档已随重构改写，对齐核心 70% / 卫星 20% 主线。核心是**月度机械换仓**（无单笔止损）；卫星是**事件 + 硬止损/时间退出**。依据 `SIGNAL_FIRST_PLAN.md` §4.1 / §4.2。

---

## A. 操盘手心智

再平衡分两条完全不同的节奏：

1. **核心 ETF — 月度结构性再平衡**：每月末按因子分重排，掉出 top6 卖、进 top4 买、其余持有。**不设单笔止损止盈**——ETF 波动小，月度调仓 + 组合级 PR-L 熔断足够风控。「每天调 = 死路」（成本吃 alpha），「不调 = 慢性中毒」（漂成重仓），月度是平衡点。
2. **卫星题材股 — 事件驱动退出**：题材一般 3-4 周就冷，所以卫星是「detector 报退潮 / 硬止损 / 时间到」三条腿硬退出，节奏快、规则不讲情面。

---

## B. 核心 ETF 再平衡（`ETFRotationService`）

### B.1 触发 + 换仓

- **频率**：每月最后交易日 22:00 计算（cron `ETF_FACTOR_ROTATION_REBALANCE`），次月第一交易日 9:40 后执行
- **缓冲带换仓**（`ETFRankingService`，`BUY_BAND=4` / `SELL_BAND=6`）：
  - 排名滑出 top6 → SELL
  - 进入 top4 → BUY（严格用 top4 避免边界抖动）
  - 仍在 top4-6 → HOLD（别折腾）
- 稳态持有 4-6 只

### B.2 执行细节（避免吃开盘价差/折溢价噪音）

| 阶段 | 时点 | 方式 |
|---|---|---|
| Pre-check | 9:25-9:35 | 观察集合竞价、盘口深度、ETF 折溢价；> 0.3% 溢价 → 推迟到 9:45 复评 |
| Split execution | 9:40-11:00 | 分 3-4 笔限价单（限价 = 上一分钟均价 ± 0.05%），每笔隔 10-20 分钟 |
| VWAP fallback | 11:00-14:00 | 未成交完 → VWAP 算法或以当天 VWAP 为参考的限价 |
| Cutoff | 14:30 | 未完成部分次日续做，不追高 |

**执行 gate（`cost_gate` L3，任一触发当日 skip 该 ETF）**：折溢价 > 0.5% / 盘口买一卖一距离 > 0.3% / 当日成交额 < 前 20 日均值 × 30% / 单次换手 > 15%。

### B.3 SELL 机制

- **只有月度再平衡触发**，不设单笔止损止盈
- 组合级 PR-L（整体大跌熔断）保留（§5.4）

## C. 卫星题材股退出（`AutoExitService`，§4.2）

常量集中在 `backend/src/services/exit/AutoExitService.ts`（`SATELLITE_HARD_STOP_PCT` 等），便于回测/调参。

| # | 规则 | 阈值 | 是否缓冲 |
|---|---|---|---|
| 1 | 硬止损/深止损 | 自成本 −15% | ❌ 无条件立即强平 |
| 2 | 止盈 | +20% | 达到即卖 |
| 3 | 时间硬退出 | 持仓满 21 交易日 | ❌ 到期无论盈亏 |
| 4 | 主动止损 | −7% | ✅ 若 detector 仍报 launch/outbreak 且盘中反弹 > 3%，允许 T+1 复核；否则次日集合竞价卖 |
| 5 | 卫星冻结 | 60 日滚动累计亏损 > 组合 5% | 冻结 30 天，只留核心 |
| 6 | 卫星永久停 | 自然月连续 3 月 alpha < 0 | 资金转入核心 |

> **两道止损分工**：−7% 是主动止损，走信号 + EV 判断、允许一天缓冲（题材股日内波幅大，硬性 −7% 即卖会被正常波动洗出）；−15% 是硬止损，不讲理、不缓冲、立即强平，是兜底。正常情况 −7% 先触发；若因缓冲未执行且继续恶化到 −15%，则 −15% 硬止损兑现。

退出走 `executeGuardSells`（`facade.placeOrder`），保留完整记账链（锁现金 / 印花税 / 佣金 / outcome 关闭）。detector 保持纯软层不动，本服务是独立的硬退出执行器（可回滚）。

### C.1 优先级（多指令冲突时）

```
PR-L 冻新单 > 单笔保护（止盈/硬止损）> 时间止损
```

---

## D. 边界

- 核心 ETF **无单笔止损止盈**；卫星个股 **有** 完整硬退出。
- 卫星 alpha = 卫星月度 PnL% − 沪深 300 月度涨跌%；严格连续，中间任一月 alpha ≥ 0 重置计数。
- 冻结期间强制持仓不动，仍计月度 alpha。
