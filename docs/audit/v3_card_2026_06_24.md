## 已知限制 (后续可改)

1. **漏斗 scanned/candidate/selected 当前从 `ai_investment_signals` 反推, 没有真实 quant pipeline 漏斗持久化** —— 数字看着合理但只反映"AI 写库了多少条", 不反映"AI 实际扫描了多少 / 筛掉多少". 后续可加 `quant_pipeline_daily_summary` 表把每日 scanned_universe_size / candidates_passed_factors_filter / final_buy_signals 三段都记下.
2. **5 档 playbook 阈值硬编码** —— `bull_breakout` ≥ 2% 涨幅 / `bull_pullback` -1% 到 +2% / `sideways` -3% 到 -1% / `weak` < -3% / `hard_break` 含高位关键字. 未来可做用户级别 / 板块级别参数化.
3. **ATR / support_level 算法简化** —— ATR 用前 14 日 high-low 平均, support 用前 20 日 min(low). 未来可换 ta-lib 或专业技术指标库实现真 ATR (含 prev_close gap) / 真 support (含 swing low + 二次确认).
4. **核心推荐 tab 走 v3 状态机, 与旧 TodaySignals 完全解耦** —— 切到旧 4 个 tab 是独立 refresh; 这是有意的, 让 v3 不影响老链路, 但首页"刷新"按钮在 core_picks tab 下走 `loadV3()`, 在其它 tab 下走 `refresh()`.
5. **funnel.scanned 字段当前固定 ≈ 200** (从 stock pool 模糊估算) —— 后续接入真 universe size 后会变成真实数 (>2000) 看着更"硬核".
