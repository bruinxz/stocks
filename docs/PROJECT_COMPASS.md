# 战略镜子 (Strategic Compass) — 月度自检模板

> **用法**: 每月第一个周末花 30-60 分钟填一次。复制本模板到 `docs/compass/YYYY-MM.md`
> (例如 `docs/compass/2026-07.md`), 然后跑数据、填 4 层。
>
> **取数**: `psql -h 127.0.0.1 -p 5432 -U bytedance -d stock_backtest -v month="'YYYY-MM'" -f scripts/compass/monthly_metrics.sql`
>
> **铁律 (§8.1)**: AI 只填客观数据 (层 1) + 算偏差 (层 2) + 给建议 (层 3 候选);
> **主观归因 (层 3 至少一条) 和决定 (层 4) 必须人手写签字**——否则机制退化, 等于"AI 说了算", 你就废了。

---

## 每题固定 4 层 (不能跳)

```
层 1: 现状  → 数据是什么           (AI 填, 客观)
层 2: 评估  → 数据相对目标偏多远    (AI 算)
层 3: 归因  → 偏在哪里             (AI 建议, 用户手写至少一条)
层 4: 决定  → continue / 小调 / 切换 / 全停  (用户签字)
```

**目标基线** (对照用):
- 结构: 核心 70% (ETF 因子轮动) + 卫星 20% (题材事件) + 现金 10% (5% 应急 + 5% 生息)
- 核心: 月度再平衡, 单 ETF ≤15%, 核心合计 ≤70%, top4 买 / top6 卖
- 卫星: 单股 ≤5%, -15% 硬止损 / -7% 缓冲止损 / +20% 止盈 / 21 交易日时间退出 / 60 天滚动亏损 >5% 冻结 30 天 / 连续 3 月 alpha<0 永久停
- 现金: 5% 应急 (不动) + 5% 生息 (511010 国债ETF + 511360 短融ETF)
