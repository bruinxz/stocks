## §2.1 规则

**禁**：`Math.random()` 调用全 backend + 因子引擎 + 卫星层信号计算

**允**：`SeededRandom(seed)` 显式播种伪随机数生成器（deterministic）

## §2.2 CI 层实现

- `eslint-plugin-no-math-random`（US-038 rule id）
- pre-commit hook grep `Math\.random\(\)` 全 backend TypeScript 代码
- 命中 = **red 断言**（PR reject）
- 例外白名单：`__tests__/**` 允许 · 但 CI mock random seed 保证确定性

## §2.3 依据

- 回测确定性可复现要求 · seed 固定 → 结果一致
- 因子引擎数值稳定性要求（`Math.random()` 引入非确定性风险）
- ADR-0001 §凭证纪律 5 铁律 · 与 §凭证纪律 并列的确定性纪律
