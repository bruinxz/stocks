# Product

## Register

product

## Users

QuantX simplified workspace is for A-share investors and beginner quant users who want to run a complete strategy workflow without learning the full professional toolset first. They arrive with limited quantitative vocabulary, need reassurance that the system is safe to explore, and want a clear next action rather than a dense dashboard.

## Product Purpose

The product turns a professional quant workflow into a guided, low-friction path: choose a strategy template, check data readiness, run a backtest, then observe a simulated strategy before moving into advanced configuration. Success means a first-time user can understand the current step, complete the next action, and know where to inspect details without feeling trapped or overwhelmed.

## Brand Personality

Calm, exact, quietly modern. The interface should feel like a trustworthy research instrument that has been simplified with care, not like a decorative marketing page or a generic AI-generated dashboard.

## Anti-references

- A crowded admin dashboard where every metric, card, and shortcut competes for attention.
- Decorative hand-drawn illustrations that feel amateurish rather than useful.
- Over-large serif type and warm parchment styling used as a generic Claude-like imitation.
- Financial trading UIs that look like terminal-heavy expert tools before the user understands the workflow.
- Blue SaaS dashboards with glass cards, gradients, or generic AI visual tropes.

## Design Principles

1. One decision per screen state. The main surface should present the current user decision; secondary details belong in progressive disclosure.
2. Earn trust through clarity. Explain risk, data readiness, and next steps in plain user language without hiding professional context.
3. Preserve an escape hatch. Users should always be able to go back, inspect details, or enter the professional workspace.
4. Let structure carry guidance. Steps, status, and primary actions should create the path without excessive instructional copy.
5. Keep personality precise. Visual identity can be distinctive, but every illustration, color, and typographic choice must support the product task.

## Accessibility & Inclusion

Target WCAG AA for contrast, visible focus states, keyboard-operable controls, and reduced-motion support. The simplified workspace should be readable for cautious first-time users, including users with lower confidence, color-vision differences, or limited financial terminology.
